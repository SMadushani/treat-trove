# 🎂 Treat Trove – AI-Powered Custom Cake Ordering Platform

Treat Trove is a modern full-stack web application designed for a custom cake and dessert business in Melbourne, Australia.

The platform goes beyond a traditional e-commerce website by introducing an **AI-assisted custom cake preview and chef-review workflow**, allowing customers to personalise cake orders, communicate with the baker, receive approval, and complete their purchase through a structured ordering process.

> **Project Status:** 🚧 Currently under active development

---

## ✨ Project Overview

Ordering a highly customised cake online can be difficult because customers often need to explain designs, colours, serving sizes, reference images, and other requirements before a baker can confirm the order.

Treat Trove is designed to simplify this process by combining:

- Custom cake configuration
- AI-assisted cake visualisation
- Reference image uploads
- Chef review and approval
- Customer–chef communication
- Online ordering and checkout
- Order tracking
- Automated email notifications
- Customer reviews

The goal is to create a smoother digital experience for both the **customer** and the **cake business owner**.

---

## 🤖 Key Feature – AI Custom Cake Preview

One of the main features of Treat Trove is the planned **AI-powered customised cake preview**.

Customers can provide information such as:

- Cake design/theme
- Reference image
- Colour preferences
- Cake size
- Weight or servings
- Number of tiers
- Special instructions

The platform is being designed to use these selections to generate a visual representation of the customised cake before the order is finalised.

This feature aims to reduce misunderstandings between customers and cake designers while giving customers greater confidence in their customised order.

---

## 👩‍🍳 Chef Review & Approval Workflow

Custom cake orders follow a different workflow from standard product purchases.

```text
Customer Customises Cake
        ↓
Uploads Design / Requirements
        ↓
AI-Assisted Cake Preview
        ↓
Submit for Chef Review
        ↓
Chef Reviews Requirements
        ↓
Customer Receives Notification
        ↓
Customer & Chef Communicate if Required
        ↓
Chef Approval
        ↓
Checkout & Payment
        ↓
Order Confirmation
        ↓
Email Receipt
```

Customers **cannot complete checkout for a customised cake until the chef has reviewed and approved the request**.

Standard products that do not require customisation can proceed directly to checkout.

## 💻 Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/SMadushani/treat-trove.git
```

Move into the project directory:

```bash
cd treat-trove
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
